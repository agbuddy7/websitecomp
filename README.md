# Roommate website

Promotional landing page for [Roommate](https://github.com/agbuddy7/Talk_rooms), a Twitch Extension that turns shared live-chat reactions into temporary viewer rooms.

## Local preview

This is a dependency-free static site. Open `index.html` directly or serve the directory with any static web server.

## Deploy on Vercel

1. Import this GitHub repository in Vercel.
2. Select **Other** as the framework preset.
3. Leave the build command empty.
4. Leave the output directory as the repository root (`.`).
5. Deploy.

No environment variables are required.
